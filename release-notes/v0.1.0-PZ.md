The first release of this ReiPan fork: the Fatal Frame 3 (Project Zero 3) PC
port with an optional **over-the-shoulder camera**, built for Windows.

## New

- **Over-the-shoulder camera**, off by default: **Options → Camera → Camera
  view → Over the shoulder**.
  - The right stick turns it and R3 puts it back behind her; it drifts back
    behind her while she walks. The left stick walks the way it is pushed, as
    the camera sees it.
  - It collides with the rooms and furniture as they are drawn: it looks over a
    low table, stops short of a wall or a closed door, and looks past ropes,
    poles and candles.
  - It also takes over walks the game films with an event camera (the dream's
    graveyard path) while you can walk. **Event cameras → Original** keeps the
    game's shot there.
  - Events that take control away, the Camera Obscura, crawling, ladders and
    the damage and death shots keep the game's own cameras. Raising the Camera
    Obscura opens it where the camera was looking.
  - Distance, height, shoulder, field of view, look speed and smoothing are on
    the same page, and saved under `[over_shoulder_camera]` in `reipan.ini`.
    The overlay (F1) has them too, under **Settings → Camera**, with a readout
    of what the camera is doing.

## Fixes

- **Options → Controls → Analog stick** described its default backwards. It
  only swaps which stick aims and which walks with the Camera Obscura raised,
  and now reads "Left aims, right walks" / "Right aims, left walks".
- The profiler's **VBlank/gate** figures were never recorded, so **Game CPU**
  included the time spent waiting for the next frame.
- The README's build command now passes `--config Release`. Visual Studio
  ignored the build type and made a Debug build, which runs at half speed or
  less.

## Installing

This build is for **Windows (64-bit)**. Only the European version of the game
works: **Project Zero 3, SLES-53825**.

1. Extract the zip anywhere and run `ReiPan.exe`.
2. The first time, it asks for your own copy of the game: the **disc image
   (.iso)**, or **IMG_BD.BIN** with `ZERO3.FHD` from the disc in the same
   folder. It remembers your choice.
3. For 60 fps camera and motion, set **Options → Graphics → Extra frames → 1
   extra**. The game still runs at its own pace.

Settings, saves and `reipan.log` are kept in ReiPan's user folder (overlay:
**Settings → Open user data folder**). Please include `reipan.log` when
reporting a problem.
